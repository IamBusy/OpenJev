# 开源了！让AI看图回答概率问题

一张图里，物体被挡住了，AI 能不能把「不确定」也表达出来？👀

最近我们开源了 OpenJev-Vision，想探索一个思路：
一张图编码一次，保留一个概率分布，让多个问题共享它。

比如在合成场景实验里，可以问：
🔴 左边的物体是红色的概率有多大？
🔵 左右两个物体颜色相同的概率呢？
🧩 两个物体同时是红色的概率呢？

这些答案来自同一份概率表示。换成遮挡更少的图片，还能观察补充视觉证据后，判断怎么变化。

这次一起公开的有：
✅ 8,192 张原创合成图像，附带生成过程定义的精确概率目标
✅ 宠物照片与颜色／形状组合实验数据
✅ 可下载的训练权重、推理示例、训练和评测代码
✅ 三组随机种子的结果，以及没做好的失败案例

有个值得继续研究的发现：在本次未见颜色／形状组合实验中，分别学习属性的简单基线，反而优于把组合当成整体类别的预测头。

目前是研究版 v0.1，支持预定义类别与事件；合成场景还需要提供先验。自由看图聊天、任意识别和通用视觉推理，都还不是当前能力。

项目受 TypeSafe 的 Jev 启发，是独立开源探索。

如果你也关注视觉模型、概率建模，或者想找一套能下载、能跑、能改的实验，欢迎来玩，也欢迎 Star / 提 Issue 🌱
