# Demos and publication materials

This directory archives the public demo source, media-generation scripts and dated
publication drafts for OpenJev-Vision. Research claims refer to the linked source
and model revisions recorded with each set of materials.

- [Launch materials, 2026-09-19](launch-2026-09-19/README.md): static ONNX demo,
  optional Gradio demo, original graphics, video and platform-specific drafts.
- [Follow-up cards, 2026-09-20](xiaohongshu-followup-2026-09-20/README.md): eight
  editable cards, rendered images, source references and publication copy.

The small ONNX file is an intentional runtime asset for the static demo. It is an
export of the already-public synthetic-scene CNN, with its checksum and numerical
comparison in the adjacent provenance file. Large model backbones, local model
caches, virtual environments and duplicate ZIP archives are not tracked.

Publication-operation notes and account-state records remain local. Drafts here
are an archive, not instructions to post to third-party platforms. Before reusing
any copy, check that its date, source references and experimental limits fit the
new context. Platform posting rules must be checked at the time of publication.

Code, original graphics and synthetic examples follow the repository's Apache-2.0
license. Referenced projects and external sources retain their own rights. These
materials do not establish affiliation with those projects or their authors.
